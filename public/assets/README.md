# Assets de ENTUSADOS

Coloca aquí las fotos reales de los productos. La app las referencia con fallback
automático: si un archivo falta, se muestra un degradado con emoji de la categoría,
así que puedes subirlas de a poco.

## Logo y arte de marca

- `logo-entusados.jpeg` → logo principal (ya instalado desde el kit de marca).
- `entusados-art.jpeg` → arte de referencia (fondo del hero y login).
- `logo-entusados.svg` → favicon / fallback.
